# ЛР4V1 — шифр гаммирования, вариант 2

Учебная реализация на Java 21 и JavaFX + FXML.

## Особенности V1

- Разрядность фиксирована: **b = 7**, модуль **M = 128**.
- Текст кодируется 7-битным ASCII: один символ = один блок (0..127). Кириллица и Unicode не поддерживаются.
- Шифротекст выводится в HEX: два символа HEX на каждый 7-битный блок. Каждое значение представлено байтом 00..7F исключительно для удобства передачи и отображения.
- Два режима: обычное гаммирование и гаммирование с обратной связью (вариант 2).
- Параметры A, C, T0 можно менять, исходные значения: 5, 3, 7.
- Флажок «Показывать расчёты по шагам» показывает формулы, 7-битные значения и XOR.
- Изменение текста или параметров очищает результаты предыдущего расчёта.

## Алгоритмы

Обычный режим: T(i) = (A * T(i-1) + C) mod 128; P(i) xor T(i).

Обратная связь: T(1) = (A * T0 + C) mod 128, а для i > 1:
T(i) = (A * bitCount(P(i-1)) + C) mod 128.
При дешифровании для обратной связи используется предыдущий **восстановленный** символ. Это соответствует числовому примеру в методичке.

## Как запустить

Откройте папку проекта как Maven-проект в IntelliJ IDEA, выберите JDK 21+ и запустите:

```bash
mvn clean javafx:run
```

Для тестов: `mvn test`.

## Классы

- `CipherConfig` — параметры A, C, T0, режим, постоянные b и M, валидация.
- `GammaCipher` — оба режима шифрования и обратное преобразование.
- `Ascii7Codec` — кодирование текста в ASCII и обратно.
- `HexCodec` — отображение и ввод шифротекста в HEX.
- `CipherStep`, `CipherResult`, `CipherMode` — модели промежуточных шагов и результата.
- `MainController` — логика интерфейса; `main-view.fxml` — расположение элементов.

Это учебный алгоритм, не предназначенный для защиты реальных секретных данных.
