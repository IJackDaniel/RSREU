Объясняю что делать, чтобы проверить подключение OpenCL.
1. Открывает main.cpp и жмём комбинацию клавиш ctrl + shift + B
2. Сверху выбираем "Build OpenCL Lab" (скорее всего выберется само автоматически)
3. После этого появится exe-шник, который надо запустить командой .\main.exe
4. Должно вывестить сообщение "OpenCL platform found: <число какое-то>"
5. Значит всё работает
